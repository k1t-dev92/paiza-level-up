# paiza-level-up

My JavaScript solutions to the [paiza Level Up](https://paiza.jp/works/mondai) problems.

## Language

- JavaScript (Node.js)

## Directory Structure

| Directory                   | Description                  |
| --------------------------- | ---------------------------- |
| `algorithms/`               | Standard algorithm menus     |
| `algorithms/bfs-dfs/`       | BFS and DFS problems         |
| `algorithms/binary-search/` | Binary search problems       |
| `algorithms/prefix-sum/`    | Prefix sum problems          |
| `algorithms/stack-queue/`   | Stack and queue problems     |
| `b-rank/dp/`                | Dynamic programming problems |

## Usage

Each solution reads from standard input, as on paiza.

```sh
node algorithms/binary-search/<file>.js < input.txt
```
